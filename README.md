# Suyog Mainali Portfolio

A modern personal portfolio website showcasing my background as a **Senior Data Engineer**, including experience, featured projects, analytics visualizations, technical skills, education, and contact information.

This portfolio is designed to present both my engineering depth and product-oriented thinking through a clean, interactive, and responsive web experience.

## Overview

The site highlights:

- My professional background and positioning as a Senior Data Engineer
- Selected data engineering, analytics, and AI-related projects
- Interactive charts and portfolio metrics
- Technical skills and tools across data, cloud, ML, and analytics
- Resume download and contact links
- A responsive UI optimized for desktop and mobile

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Chart.js** for interactive visualizations
- **Google Fonts**
